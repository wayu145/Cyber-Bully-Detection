# Cyber Bully Detection 🛡️

**Cyber Bully Detection** คือ Web Application สำหรับตรวจสอบข้อความภาษาไทยที่อาจมีลักษณะการกลั่นแกล้งหรือการรังแกบนโลกไซเบอร์ (Cyberbullying) โดยเชื่อมต่อกับ **AIForThai Cyber Bully API** จาก NECTEC และนำเสนอผลลัพธ์ผ่านหน้าจอส่วนติดต่อผู้ใช้ (UI) ที่สวยงาม ทันสมัย และใช้งานง่ายด้วย Streamlit เหมาะสำหรับเป็นโปรเจกต์ศึกษาและนำไปต่อยอดในงานวิจัย

---

## 1. วัตถุประสงค์ของโปรเจกต์ (Project Objective)
- พัฒนาระบบคัดกรองและประเมินข้อความภาษาไทย เพื่อระบุลักษณะและประเภทของการรังแกทางไซเบอร์
- เชื่อมต่อและประมวลผลข้อมูลจาก AIForThai Cyber Bully API จริงผ่านรูปแบบ HTTP POST (x-www-form-urlencoded)
- ช่วยเสริมสร้างความปลอดภัยในการสื่อสารบนสังคมออนไลน์ โดยให้ข้อมูลเชิงวิเคราะห์ประกอบการตัดสินใจของมนุษย์

---

## 2. เทคโนโลยีที่ใช้ (Technology Stack)
- **ภาษาโปรแกรม:** Python 3.11+
- **การพัฒนา UI:** [Streamlit](https://streamlit.io/)
- **การเชื่อมต่อ API:** Requests
- **การจัดการ Environment Variable:** python-dotenv
- **การทดสอบระบบ (Testing):** Pytest

---

## 3. ความสามารถของระบบ (Features)
- 📝 **กล่องป้อนข้อความภาษาไทย:** รองรับการพิมพ์หรือวางข้อความ พร้อมระบบจำกัดความยาวสูงสุด 1,000 ตัวอักษร
- 🔢 **ตัวนับจำนวนตัวอักษรแบบ Real-time:** แสดงความยาวตัวอักษรปัจจุบันเทียบกับขีดจำกัด (เช่น `45 / 1,000 ตัวอักษร`)
- 🏷️ **จำแนกประเภทการรังแก (Bully Classification):** แปลงรหัสผลลัพธ์จาก API เป็นภาษาไทยที่เข้าใจง่าย รองรับทั้งกรณีผลลัพธ์เดี่ยวและหลายประเภทพร้อมกัน (List)
- 🔍 **ระบุคำหรือวลีที่เกี่ยวข้อง (Bully Words):** ดึงคำที่มีความเสี่ยงหรือคำรุนแรงมาแสดงเป็นแท็กอย่างชัดเจน
- 🛡️ **ระบบรักษาความปลอดภัย:** ไม่เปิดเผยและไม่บันทึก API Key ใน Source Code หรือ Log
- ⚡ **การจัดการข้อผิดพลาดครบวงจร:** แจ้งเตือนภาษาไทยเมื่อเกิดข้อผิดพลาด เช่น ลืมกรอกข้อความ, ข้อความยาวเกินกำหนด, API Key ไม่ถูกต้อง, หรือเซิร์ฟเวอร์ขัดข้อง

## 5. วิธีติดตั้ง Dependencies (Installation)

1. ตรวจสอบว่าเครื่องมี **Python 3.10+** และ **pip** ติดตั้งอยู่แล้ว
2. เปิด Terminal หรือ PowerShell แล้วเข้าไปที่โฟลเดอร์โปรเจกต์:
   ```bash
   cd cyber-bully-detection
   ```
3. ติดตั้งไลบรารีที่จำเป็นด้วยคำสั่ง:
   ```bash
   pip install -r requirements.txt
   ```

---

## 6. วิธีตั้งค่า API Key (Configuration)

โปรเจกต์นี้เชื่อมต่อกับ **AIForThai Cyber Bully API** จริง จึงจำเป็นต้องมี API Key

1. สมัครสมาชิกและขอรับ API Key ฟรีได้ที่ [AIForThai (NECTEC)](https://aiforthai.in.th/)
2. คัดลอกไฟล์ตัวอย่าง `.env.example` ไปเป็น `.env`:
   ```bash
   cp .env.example .env
   # บน Windows PowerShell:
   Copy-Item .env.example .env
   ```
3. เปิดไฟล์ `.env` แล้วใส่ API Key จริง:
   ```env
   AIFORTHAI_API_KEY=ใส่_API_Key_ของท่านที่นี่
   ```
> [!NOTE]
> หากไม่ได้สร้างไฟล์ `.env` สามารถตั้งค่าผ่าน Environment Variable ในระบบ หรือกรอกในช่อง "AIForThai API Key (ชั่วคราว)" บนแถบด้านข้าง (Sidebar) ของหน้าเว็บได้เช่นกัน

## 8. วิธีใช้งานระบบ (User Guide)
1. **กรอกข้อความ:** พิมพ์หรือวางข้อความภาษาไทยที่ต้องการตรวจสอบลงในช่องข้อความ
2. **ตรวจนับตัวอักษร:** สังเกตตัวนับตัวอักษรด้านล่างช่องข้อความ โดยระบบจำกัดไม่เกิน 1,000 ตัวอักษร
3. **ตรวจสอบข้อความ:** คลิกปุ่ม **"🔍 ตรวจสอบข้อความ"** ระบบจะส่งคำขอไปยัง AIForThai API
4. **ดูผลลัพธ์:**
   - **ข้อความต้นฉบับ:** ข้อความที่ถูกส่งไปวิเคราะห์
   - **ผลการจัดประเภท:** แสดงประเภทการรังแก (หากเป็นรหัส 0 จะแสดงเป็นข้อความทั่วไป)
   - **คำที่เกี่ยวข้อง:** แสดงคำหรือวลีที่ API ตรวจพบ
5. **ล้างข้อความ:** คลิกปุ่ม **"🗑️ ล้างข้อความ"** เพื่อเคลียร์กล่องข้อความและผลลัพธ์ทั้งหมด

## 9. ความหมายของรหัส bully_type

| รหัส bully_type | ความหมายภาษาไทย |
| :---: | :--- |
| `0` | ข้อความทั่วไปที่ไม่มีลักษณะของการรังแก |
| `1` | ข้อความที่กล่าวถึงบุคลิก รูปลักษณ์ และพฤติกรรม |
| `2` | ข้อความด่าทอหรือคำหยาบคาย |
| `3` | ข้อความคุกคามทางเพศ |
| `4` | ข้อความที่กล่าวถึงเชื้อชาติ กำเนิด และการใช้ชีวิต |
| `5` | ข้อความที่กล่าวถึงสติปัญญาและความฉลาด |
| `6` | ข้อความที่ใช้ถ้อยคำรุนแรงหรือข่มขู่ |

*หมายเหตุ: หาก API ส่งรหัสประเภทที่ไม่รู้จัก ระบบจะแสดงรหัสเดิมและระบุว่า "รหัสประเภทที่ไม่รู้จัก" โดยไม่ทำให้ระบบหยุดทำงาน*

## 10. วิธีแก้ปัญหาเมื่อ API เรียกใช้งานไม่ได้ (Troubleshooting)

| ปัญหาที่พบ | สาเหตุที่เป็นไปได้ | แนวทางแก้ไข |
| :--- | :--- | :--- |
| **"ไม่พบ API Key สำหรับ AIForThai"** | ยังไม่ได้กำหนดตัวแปร `AIFORTHAI_API_KEY` | สร้างไฟล์ `.env` หรือกรอกคีย์ในแถบ Sidebar ของหน้าเว็บ |
| **"API Key ไม่ถูกต้อง หรือไม่มีสิทธิ์เข้าถึงบริการ (HTTP 401/403)"** | คีย์หมดอายุ ผิดพลาด หรือยังไม่ได้รับสิทธิ์เปิดบริการ Cyber Bully | ตรวจสอบความถูกต้องของ API Key บนหน้าเว็บ AIForThai |
| **"การเชื่อมต่อหมดเวลา (Timeout)"** | เครือข่ายอินเทอร์เน็ตล่าช้า หรือเซิร์ฟเวอร์ AIForThai มีผู้ใช้งานหนาแน่น | ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต แล้วกดตรวจสอบใหม่อีกครั้ง |
| **"ไม่สามารถเชื่อมต่อกับเซิร์ฟเวอร์ AIForThai ได้"** | ปัญหาเครือข่าย อินเทอร์เน็ตหลุด หรือโดนบล็อก Firewall | ตรวจสอบสถานะการเชื่อมต่ออินเทอร์เน็ต หรือ DNS |
| **"ข้อความยาวเกินกำหนด"** | ผู้ใช้ป้อนข้อความเกิน 1,000 ตัวอักษร | ย่อหรือตัดทอนข้อความให้ไม่เกิน 1,000 ตัวอักษรตามสเปก API |

สามารถรันชุดทดสอบด้วย Pytest ได้ด้วยคำสั่ง:

